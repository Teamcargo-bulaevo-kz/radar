# Радар — звуковой сканер для Android

Приложение превращает телефон в **сонар**: динамик излучает тихий ультразвуковой сигнал (чирп), микрофон ловит эхо, математика считает расстояния до стен и предметов. Рядом — ночная камера, нейросеть глубины, пульсометр, анализ мерцания и вибраций, анализатор спектра и металлоискатель.

**Скачать APK:** https://github.com/Teamcargo-bulaevo-kz/radar/releases/download/latest/Radar.apk
(обновляется после каждой сборки; новую версию можно ставить поверх старой)

## Установка
1. Откройте ссылку на телефоне, скачайте `Radar.apk`.
2. Разрешите установку из этого источника (Android спросит сам).
3. При первом запуске разрешите микрофон и камеру.

## Вкладки
| Вкладка | Что делает |
|---|---|
| Карта | Круговая карта комнаты: поворачиваетесь на месте — проявляются стены и предметы, голубая линия — контур, подписи в метрах у ближайших объектов, кнопка масштаба |
| Дальн. | Расстояние до ближайшего предмета, график эха, парктроник: гудки (чем ближе, тем чаще и выше) и вибрация |
| Ходьба | Ориентирование в темноте и на улице: водите телефоном влево-вправо, как фонарём; веер показывает препятствия, подсказка — куда обойти, гудки — насколько близко |
| Движ. | Видит только движущееся (неподвижное вычитается), режим «Охрана» с сигналом тревоги |
| Спектр | Анализатор спектра до 24 кГц, водопад — видно ультразвук вокруг |
| Камера | Ночное видение из слабого света: накопление кадров, контуры, палитры, снимки в галерею; режим «ИК» для ИК-фонарика (850 нм); кнопка «ИК» — тест, видит ли камера инфракрасный свет (мигает встроенный ИК-порт) |
| Глуб. | Нейросеть по кадру камеры показывает, что ближе, что дальше (красное — близко, синее — далеко); с включённым сонаром — расстояние в метрах до точки в перекрестии. Нейросеть (MiDaS v2.1 small) скачивается один раз при первом запуске вкладки |
| Пульс | Пульс без датчиков: по лицу (фронтальная камера видит еле заметное покраснение кожи), по пальцу (задняя камера + вспышка), по звуку сердца (микрофон к груди, можно слушать в проводных наушниках как стетоскоп). Не медицинский прибор и не ЭКГ |
| Вибро | То, что глазу не видно: мерцание ламп и экранов (частота и глубина, по полосам на кадре), усиление микродвижений в кадре (дыхание, пульс на коже, дрожание), спектр вибрации по акселерометру с оценкой в мм/с |
| Металл | Магнитометр: поиск металла и проводки; карта стены — ведёте телефон строками, получается картинка арматуры, труб, проводки |
| Сервис | Подбор лучшего диапазона (свип-тест), проверка наушников как излучателей, проверка камер (датчик глубины, RAW, выдержка, скрытые камеры) и ИК-порта, самотест математики, сведения о телефоне, инструкция |

## Как пользоваться
1. Громкость медиа на максимум, наушники отключить.
2. «Сервис» → «Подобрать диапазон» (8 секунд) — приложение само выберет, на каких частотах динамик и микрофон работают лучше.
3. «Карта» → «Старт». Держите телефон горизонтально, нижним краем (там динамик) вперёд, как пульт, и медленно (15–20 с) повернитесь на 360°.

## Честно о возможностях
- Это звуковой радар, а не камера: он измеряет расстояния (точность несколько сантиметров) и рисует очертания, но «фото» не даёт.
- Хорошо видны большие твёрдые поверхности. Мягкое (диван, шторы) поглощает звук.
- Дальность: 3.5 / 7 / 14 м (на практике в комнате 3–7 м).
- Один динамик и один микрофон — направление определяется поворотом телефона (датчик ориентации), а не антенной решёткой.
- Ультразвук телефонного динамика на разных моделях слабее или сильнее; тест на вкладке «Сервис» выбирает диапазон автоматически, при слабом ультразвуке переходит на слышимый (будет свистеть).
- Камера видит только свет. В полной темноте она слепа — там работает сонар. С ИК-фонариком (850 нм) камера видит в темноте, если её матрица пропускает ИК (проверка — кнопка «ИК» на вкладке «Камера»). Встроенный ИК-порт телефона для подсветки слишком слабый.
- Нейросеть глубины знает только «ближе/дальше», метры даёт сонар; это оценка, а не измерение, особенно далеко от ближайшего предмета.
- Ультразвук может беспокоить домашних животных.
- Пульс и звук сердца — для интереса, а не для диагноза: на точность влияют свет, движение, шум. Это не медицинский прибор.
- Магнитометр чувствует металл и проводку только вблизи (несколько сантиметров); «просканировать комнату» на расстоянии им нельзя. Положение телефона на стене датчики не знают, поэтому карта стены точна, если вести телефон ровно и с одинаковой скоростью.

## Устройство проекта
- Java, весь интерфейс собран кодом. Единственная сторонняя библиотека — TensorFlow Lite для нейросети глубины; сама модель не в APK, а скачивается приложением.
- `dsp/` — чистая математика (FFT, чирп, деконволюция, карта комнаты, анализ спектра, ночное усиление); проверяется симуляцией (`SelfTest`, юнит-тест и кнопка в приложении).
- `audio/`, `sensors/`, `camera/` — работа с железом; `ui/` — вкладки.
- Сборка: GitHub Actions (`.github/workflows/build.yml`): компиляция, тесты, запуск в эмуляторе с обходом вкладок и скриншотами.

## О ключе подписи
`app/radar.keystore` (пароль `radar-sonar`) лежит в репозитории намеренно: проект любительский и открытый, ключ нужен только чтобы обновления ставились поверх друг друга. Для публикации в магазине его нужно заменить на свой.
